# Crime and Punishment — Interactive Literary Edition

A quiet, procedural 3D reading environment for Fyodor Dostoevsky's *Crime and Punishment*. This first vertical slice includes the title screen, a data-driven reader, a miniature room scene, procedural Web Audio ambience, responsive controls, bookmarks, progress, and reduced-motion support.

## Run

```bash
npm install
npm run dev
```

`npm run build` type-checks and builds the static application. `npm test` validates the book data.

## Edition

The included opening is a public-domain excerpt from the Constance Garnett translation (1914), sourced from Project Gutenberg. The scene is an interpretive visual environment, not an illustration of every detail in the text.
